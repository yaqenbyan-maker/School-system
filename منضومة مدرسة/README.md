# 🎓 Student Affairs Management System

نظام إدارة شؤون الطلاب (Student Management System) هو تطبيق مكتبي (Desktop Application) مصمم بلغة **Python** باستخدام مكتبة الواجهات الرسومية **Tkinter** وقاعدة بيانات **SQLite**. يتيح التطبيق للمؤسسات التعليمية إدارة بيانات الطلاب وسجلاتهم الأكاديمية بكفاءة عالية وبواجهة عصرية مريحة للعين.

---

## ✨ المميزات والخصائص الرئيسية

- **واجهة مستخدم عصرية (Modern UI):** تصميم أنيق يدعم الوضع المظلم (Dark Mode) مع استخدام خطوط واضحة وألوان متناسقة (`#0f172a` و `#1e293b`).
- **إدارة كاملة للبيانات (CRUD Operations):**
  - **حفظ (Save):** إدخال بيانات طالب جديد مع التحقق من عدم تكرار رقم المعرف (ID).
  - **تحديث (Update):** تعديل بيانات أي طالب مسجل بكل سهولة.
- **حذف (Delete):** إزالة سجل الطالب من قاعدة البيانات مع رسالة تأكيد لحماية البيانات من الحذف الخاطئ.
- **بحث فوري (Quick Search):** إمكانية البحث الفوري عن الطلاب باستخدام رقم المعرف (ID) أو الاسم الكامل (Name).
- **قوائم منسدلة منظمة:** تحديد العمر، الجنس، والمرحلة الدراسية من خلال قوائم جاهزة لتجنب أخطاء الإدخال.
- **تفاعل ذكي مع الجدول:** عند النقر على أي طالب في جدول العرض، يتم ملء حقول الإدخال تلقائياً لتسهيل التعديل أو الحذف.

---

## 🛠️ التقنيات المستخدمة

- **Python 3.x**
- **Tkinter** (مكتبة بناء واجهات المستخدم المدمجة في بايثون)
- **ttk** (مكونات الواجهة المتقدمة والمحسنة في Tkinter)
- **SQLite3** (قاعدة بيانات محلية خفيفة وسريعة)

## 📂 هيكل قاعدة البيانات (`school_system.db`)

يحتوي النظام على جدول واحد باسم `students` بالحقول التالية:

| اسم الحقل (Column) | النوع (Type) | الوصف |
| :--- | :--- | :--- |
| `id` | TEXT (Primary Key) | رقم المعرف الفريد للطالب |
| `name` | TEXT (NOT NULL) | الاسم الكامل للطالب |
| `age` | TEXT (NOT NULL) | العمر |
| `gender` | TEXT (NOT NULL) | الجنس (ذكر / أنثى) |

| `grade` | TEXT (NOT NULL) | المرحلة الدراسية |

   افتح موجه الأوامر (Terminal / Command Prompt) في نفس مجلد الملف ثم اكتب الأمر التالي:

   💡 كيفية الاستخدام
إضافة طالب جديد: قم بملء الحقول المطلوبة (رقم المعرف، الاسم، العمر، الجنس، الهاتف، والمرحلة الدراسية)، ثم اضغط على زر "💾 Save Record".
